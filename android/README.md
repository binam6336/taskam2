# اپلیکیشن اندروید تسکام

پوسته‌ی اندروید پنل تسکام: همان پنل وب (کاربر و مدیر) بدون هیچ تغییری در فرانت، داخل WebView اجرا می‌شود.
بک‌اند (PHP + MySQL) روی سرور می‌ماند؛ برنامه فقط به آدرس سرور وصل می‌شود.

## رفتار برنامه
- **آدرس سرور ثابت است:** `https://mahyarsalehee.ir/taskam` (در `app/build.gradle`). برنامه مستقیم به آن وصل می‌شود و کاربر آدرس را نمی‌بیند و نمی‌تواند عوضش کند. برای سرور دیگر، APK با `-PserverUrl=` دوباره ساخته می‌شود.
- **گواهی SSL ناقص:** اگر سرور گواهی واسط (intermediate) را نفرستد، کروم آن را خودش دانلود می‌کند ولی WebView نه. `AiaTrust` همین کار کروم را انجام می‌دهد: گواهی واسط را از نشانی «CA Issuers» داخل گواهی می‌گیرد و فقط وقتی می‌پذیرد که زنجیره به یک ریشه‌ی معتبر اندروید برسد، نام دامنه درست باشد و گواهی منقضی نباشد. این فقط برای همان سرور است. راه‌حل اصلی این است که روی سرور گواهی کامل (fullchain) نصب شود.
- **لینک‌ها:** صفحه‌های همان سرور داخل برنامه باز می‌شوند. `tel:`، `mailto:` و سایت‌های دیگر در برنامه‌ی مربوط باز می‌شوند.
- **پنجره‌ی جدید** (`window.open` / `target=_blank`، مثل «ورود به پنل کاربر» از پنل مدیر) به‌صورت یک لایه روی صفحه باز می‌شود و دکمه‌ی بازگشت آن را می‌بندد.
- **دکمه‌ی بازگشت:** به ترتیب پنجره‌ی باز (modal، با همان `TK.modal.tryClose`)، منوی کناری یا dropdown را می‌بندد، بعد به صفحه‌ی قبل برمی‌گردد و در آخر از برنامه خارج می‌شود.
- **پیوست‌ها:** انتخاب فایل (تکی و چندتایی) با انتخاب‌گر فایل اندروید انجام می‌شود.
- **دانلود:** فایل‌ها همراه کوکی نشست و همان User-Agent در پوشه‌ی Downloads ذخیره می‌شوند (`Downloader`، با همان بررسی گواهی) و بعد پیشنهاد باز کردن داده می‌شود. نام فارسی از `filename*=UTF-8''` خوانده می‌شود.
- **قطع اتصال:** صفحه‌ی «اتصال برقرار نشد» با دکمه‌ی «تلاش دوباره» و کد دقیق خطا (مثل `ERR -2` یا `SSL UNTRUSTED`) برای عیب‌یابی نمایش داده می‌شود. گواهی SSL نامعتبر هرگز پذیرفته نمی‌شود.
- **رنگ نوار وضعیت** از `meta[name=theme-color]` همان صفحه گرفته می‌شود، پس با تم تیره و روشن هماهنگ است.
- **User-Agent:** به UA معمولی WebView عبارت ` TaskamAndroid/<نسخه>` اضافه می‌شود. سرور در صورت نیاز می‌تواند برنامه را از روی آن تشخیص دهد.
- **اعلان‌ها:** Web Push در WebView پشتیبانی نمی‌شود. وقتی برنامه باز است، اعلان‌ها مثل قبل به‌صورت toast داخل پنل نمایش داده می‌شوند.

## ساخت APK
پیش‌نیازها: JDK 17+ و Android SDK (platform 35، build-tools 35).

```bash
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew assembleRelease                                   # سرور https://mahyarsalehee.ir/taskam
./gradlew assembleRelease -PserverUrl=https://example.com   # سرور دیگر
```

خروجی: `android/app/build/outputs/apk/release/app-release.apk`

### امضا
`android/keystore.properties` و فایل کلید در پوشه‌ی `android/keystore/` در گیت نیستند، چون ریپو عمومی است:

```
storeFile=keystore/taskam-release.jks
storePassword=...
keyAlias=taskam
keyPassword=...
```

اگر این فایل نباشد، APK با کلید debug امضا می‌شود. **برای اینکه نسخه‌های بعدی روی نسخه‌ی نصب‌شده آپدیت شوند، باید همیشه با همان کلید امضا شوند.** پس کلید را نگه دارید. با کلید دیگر، کاربر باید برنامه را حذف و دوباره نصب کند.

برای انتشار نسخه‌ی جدید، `versionCode` (یکی بیشتر) و `versionName` را در `app/build.gradle` بالا ببرید.

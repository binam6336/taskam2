# تسکام v2 — بازنویسی کامل (PHP MVC)

مدیریت وظایف، تیکت، تماس، همکاران، پروژه، چت و API — بازنویسی از صفر با معماری MVC، تم سبز/مشکی یکپارچه و امنیت ارتقا‌یافته.

## نیازمندی‌ها
- PHP **7.4+** (پیشنهادی 8.2 یا بالاتر) با افزونه‌های `pdo_mysql`, `mbstring`, `fileinfo`, `gd`
- MySQL 5.7+/8 یا MariaDB 10.3+
- Apache (mod_rewrite) یا Nginx — نمونه‌ی پیکربندی در `docs/DEPLOY.md`
- بدون Composer و بدون وابستگی خارجی (فقط فونت Vazirmatn و FontAwesome از CDN)

## نصب سریع (دیتابیس خام)
```bash
cp .env.example .env            # و مقادیر DB_* و APP_KEY را پر کنید
mysql -u root -p -e "CREATE DATABASE taskam CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci"
mysql -u root -p taskam < database/schema.sql
php bin/create-admin.php 09120000000 "مدیر" "سیستم"   # ساخت مدیر اولیه
chmod -R 750 storage                                    # دسترسی نوشتن برای وب‌سرور
```
بعد Document Root را روی پوشه‌ی `public/` بگذارید. روی هاست اشتراکی که نمی‌شود Document Root را عوض کرد، `.htaccess` ریشه همه‌چیز را به `public/` هدایت و پوشه‌های حساس را مسدود می‌کند.

## مهاجرت از نسخه‌ی قدیمی
راهنما: `docs/MIGRATION.md` و اسکریپت `database/migrations/001_import_from_legacy.sql` (غیرمخرب؛ دیتابیس قدیمی دست‌نخورده می‌ماند).

## ساختار پروژه
```
public/            تنها پوشه‌ی قابل دسترس از وب (index.php، assets/css/app.css، assets/js/)
app/Core/          هسته: Router, Request, Response, DB, Session, Csrf, Auth, View, Uploader, Throttle, Audit ...
app/Middleware/    auth, panel, admin, guest, csrf, api
app/Models/        کوئری‌ها (هر جدول/دامنه یک Model)
app/Services/      منطق کسب‌وکار مشترک وب و API (TaskService, ProjectService, Access ...)
app/Controllers/   کنترلرهای وب + Api/V1/*
app/Views/         قالب‌ها (layouts, partials, صفحه‌ها)
config/            routes.php, api_spec.php (منبع مستندات API), quick_links.php
database/          schema.sql + migrations/
storage/           لاگ، سشن، فایل‌های آپلودی (خارج از webroot)
docs/              مستندات فنی
```

## مستندات API
صفحه‌ی زیبا و تعاملی (با «امتحان زنده») در `/docs`. منبع آن `config/api_spec.php` است و همین فایل پاسخ `GET /api/v1/` را هم می‌سازد؛ پس مستندات و API همیشه همگام‌اند.

## معماری فرانت‌اند
- **یک** فایل استایل: `public/assets/css/app.css` (متغیرهای طراحی، دکمه‌ها، فرم، جدول، مودال، چت، مستندات …)
- **یک** هسته‌ی JS: `public/assets/js/app.js` (فضای نام `TK`: http، toast، modal، فرم‌های AJAX، نمودار SVG) + یک ماژول کوچک برای هر صفحه در `modules/`
- بدون inline-script (CSP سخت‌گیرانه: `script-src 'self'`)

## ویژگی‌های نسخه‌ی جاری
- **تقویم شمسی و ساعت آنالوگ (AM/PM)** در فرم تسک؛ امروز با رنگ متفاوت مشخص است و تاریخ پیش‌فرض تسک جدید «امروز» است.
- **سیستم زنده‌ی یکپارچه (AJAX):** لیست تسک‌ها، تماس‌ها، همکاران، پروژه‌ها، پشتیبانی و مدیریت کاربران بدون رفرش به‌روز می‌شوند؛ نشان‌های سایدبار (پیام، پشتیبانی، همکاران، پروژه‌ها، تسک‌ها) هر چند ثانیه تازه می‌شوند.
- **اعلان مرورگر:** پیام جدید («پیام جدید – نام فرستنده») و یادآوری تسک در لحظه‌ی ساعت سررسید («یادآوری وظیفه – عنوان») روی هر صفحه‌ی پنل؛ کلیک روی اعلان کاربر را به گفتگو/تسک می‌برد. برای فعال‌سازی روی زنگ بالای صفحه کلیک کنید. (اعلان فقط وقتی کار می‌کند که یک تب پنل باز باشد؛ اعلان در حالت بسته‌بودن مرورگر نیازمند Web Push است.)
- **مستندات API** با چیدمان سه‌ستونه، صفحه‌ی اختصاصی «ارسال توکن»، جدول توضیح همه‌ی فیلدهای JSON، نمونه‌ی درخواست/پاسخ/خطا و «امتحان زنده»: `/docs`.
- **نشست ورود:** گزینه‌ی «من را به خاطر بسپار» در صفحه‌ی ورود. فعال: نشست تا ۳۰ روز (`SESSION_REMEMBER_DAYS`)؛ غیرفعال: خروج پس از ۱ ساعت عدم فعالیت (`SESSION_IDLE_MINUTES`). درخواست‌های پس‌زمینه (اعلان/polling) نشست غیرفعال را زنده نگه نمی‌دارند.
- **فیلد موبایل:** «۰۹» ابتدای فیلد ثابت و غیرقابل‌حذف است؛ کاربر فقط ۹ رقم بعدی را می‌نویسد.
- **رمزگذاری چت:** با تنظیم `ENCODE_PASSWORD` در `.env`، متن پیام‌ها و نام فایل‌ها در دیتابیس به‌صورت `enc:v1:…` (AES-256-GCM) ذخیره می‌شود و در چت متن اصلی نمایش داده می‌شود. جزئیات و دستورها: `docs/SECURITY.md`.

## به‌روزرسانی دیتابیس موجود
> از v3.0.2 برنامه ستون‌ها/جدول‌های migrationهای ۰۰۴ تا ۰۰۹ را اگر جا افتاده باشند در اولین درخواست خودش اضافه می‌کند (کاربر دیتابیس باید مجوز ALTER/CREATE داشته باشد). اجرای دستی زیر همچنان روش توصیه‌شده است.

اگر قبلاً نصب کرده‌اید، فایل‌های پوشه‌ی `database/migrations/` را به ترتیب شماره روی دیتابیس اجرا کنید (هر فایل فقط یک بار):

mysql -u root -p taskam < database/migrations/008_support_desk.sql                          # v2.4: میز پشتیبانی (پیوست + در حال انجام)

## تسک‌ها و تحلیل پروژه
- **نقش کاربر در پروژه:** در پروژه‌ها ← 🔑 ← تب «نقش کاربر» (تب اول): مدیر کل، مدیر واحد، سرپرست، عضو و بدون دسترسی — پکیج‌های آماده‌ی دسترسی تسک، پروژه، برد و «مشاهده‌ی تسک‌ها». نقش برای هر پروژه جداست و از روی دسترسی‌ها تشخیص داده می‌شود (هر تغییر دستی = «سفارشی»). هر کاربر نقش خودش را به‌صورت برچسب روی کارت پروژه می‌بیند. تعریف پکیج‌ها: `Access::ROLES` در `app/Services/Access.php`.
- **برد تیمی (کانبان، دمو — هنوز در منو نیست):** از آدرس `/board`. شش ستون Backlog، To Do، In Progress، Blocked (با علت توقف)، In Review و Done؛ جابه‌جایی با کشیدن و رها کردن یا منوی ⋮ کارت. دسترسی برد جدا از دسترسی تسک و به ازای هر پروژه است (پروژه‌ها ← 🔑 ← تب «دسترسی برد تیمی»؛ پیش‌فرض بسته): «مشاهده‌ی تسک‌های» (هر کس پیش‌فرض فقط تسک‌های خودش را می‌بیند؛ با انتخاب اعضای پروژه، تسک‌هایی که مسئولشان آن‌ها هستند هم در برد او دیده می‌شود)، هر گام جلو در مسیر Backlog ← To Do ← In Progress ← In Review ← Done، مسدود کردن، رفع مسدودی، بازگرداندن به مرحله‌ی قبل و جابه‌جایی آزاد. سازنده‌ی تسک و سازنده‌ی پروژه همه‌ی دسترسی‌ها را دارند. آیکون برد در جزئیات تسک، برد پروژه را با همان کارت برجسته باز می‌کند (`/board?task=ID`). ستون Done با وضعیت انجام‌شده‌ی تسک همگام است. برای پخش داده‌ی آزمایشی بین ستون‌ها: `database/seeds/demo_board.sql`.
- **اولویت درصدی:** در تنظیمات پروژه «نوع اولویت» دسته‌بندی یا درصدی است. در حالت درصدی، اولویت با نوار سبز ← زرد ← قرمز (مضرب ۵٪) ثبت و همه‌جا به‌صورت درصد نمایش داده می‌شود؛ تغییر به درصدی: کم ۲۵٪، متوسط ۵۰٪، زیاد ۷۵٪.
- **فهرست تسک‌ها:** مرتب‌سازی (تاریخ انجام، اولویت، تاریخ ایجاد، پروژه، موضوع) و دکمه‌ی فیلتر (عقب‌افتاده / امروز / فردا / هر تاریخ سررسید موجود، اولویت بیشتر/کمتر، پروژه).
- **فرم تسک:** افزودن سریع موضوع از داخل فهرست موضوع‌ها؛ با نوشتن یا پیست لینک (http/https) در توضیحات، پاپ‌اوری برای عنوان لینک باز می‌شود و لینک در جزئیات تسک با همان عنوان و در تب جدید باز می‌شود.
- **جزئیات تسک:** آیکون ویرایش، یادداشت‌ها از جدید به قدیم، و دکمه‌ی سبز @ برای منشن اعضای پروژه (به فرد منشن‌شده اعلان می‌رود).
- **امنیت تسک‌ها (پروفایل):** مشاهده‌ی تسک با لینک برای «اعضای پروژه» (پیش‌فرض)، «همکاران»، «فقط من» یا «همه». کاربر بدون دسترسی پیام خطا می‌گیرد و به تسک‌های خودش برمی‌گردد.
- **تحلیل پروژه:** نمایش عدد با هاور روی نمودارها، رنگ متفاوت «ایجادشده/انجام‌شده»، نوار «پیشرفت سرعت» هر عضو، KPI میانگین زمان انجام، خلاصه‌ی متنی با ارزیابی (بسیار عالی تا خیلی بد)، توزیع موضوعات و نمودار مقایسه‌ی سرعت حداکثر ۵ کاربر در بازه‌های ۲ روز تا از ابتدا. فرمول امتیاز در `app/Services/TaskAnalytics.php` است.

## تنظیمات ظاهری (تم)
- در **پروفایل ← تنظیمات ظاهری** کاربر تم را انتخاب می‌کند: «شب سبز» (تیره، پیش‌فرض) یا «سبز روشن» (با رنگ‌های `#7FB77E` و `#F7F6DC`).
- انتخاب در ستون `users.theme` ذخیره می‌شود، پس روی هر دستگاهی که کاربر وارد شود همان تم را می‌بیند.
- تم‌ها در `config/themes.php` تعریف شده‌اند و رنگ‌هایشان در انتهای `public/assets/css/app.css` (`html[data-theme="…"]`) است.

## گفتگو (چت)
- **نمایش تصویر داخل پنل:** کلیک روی تصویر، نمایشگری با بزرگ‌نمایی/کوچک‌نمایی (دکمه، چرخ موس، دوبار کلیک، کلیدهای + و - و 0)، جابه‌جایی با کشیدن و دانلود باز می‌کند.
- **راست‌کلیک روی پیام:** کپی متن، دانلود (پیام فایل‌دار)، بازارسال، ویرایش و حذف پیام. حذف فقط برای پیام‌های خود کاربر و تا ۱ ساعت بعد از ارسال ممکن است و همیشه دوطرفه است. روی موبایل از دکمه‌ی ⋮ کنار پیام استفاده کنید.
- **راست‌کلیک روی مخاطب:** «حذف تاریخچه» — گفتگو فقط برای خود کاربر خالی می‌شود و طرف مقابل پیام‌ها را می‌بیند.

## نسخه‌ی PWA (نصب روی موبایل و کامپیوتر)
- **نصب:** سایدبار ← تنظیمات ← «نصب» (`/install`). دکمه‌ی «نصب» پنجره‌ی نصب کروم/اج را باز می‌کند؛ روی اندروید تسکام با آیکن خودش مثل یک برنامه روی صفحه‌ی اصلی می‌نشیند و تمام‌صفحه اجرا می‌شود. در آیفون: سافاری ← اشتراک‌گذاری ← «افزودن به صفحه‌ی اصلی».
- **اعلان‌ها (Web Push):** در همان صفحه «فعال‌سازی اعلان‌ها» (یا زنگ بالای صفحه). پیام‌های چت، واگذاری تسک، منشن، درخواست تماس و یادآوری مهلت تسک‌ها حتی وقتی برنامه بسته است با صدا، لرزش، آیکن تسکام و نشان نوار وضعیت اندروید می‌رسند؛ کلیک روی اعلان همان صفحه را باز می‌کند و تعداد پیام‌های خوانده‌نشده روی آیکن برنامه نمایش داده می‌شود.
- **پیش‌نیازها:** HTTPS، افزونه‌ی PHP `openssl` (و ترجیحاً `curl`) و اجرای migration 007. کلیدهای VAPID خودکار در `storage/vapid.json` ساخته می‌شوند (یا از `.env`)؛ این فایل را پاک نکنید، وگرنه همه باید دوباره اعلان را فعال کنند.
- **یادآوری دقیق تسک‌ها:** سایت با هر بازدید حداکثر دقیقه‌ای یک‌بار یادآوری‌ها را می‌فرستد. برای دقت کامل یک کران‌جاب دقیقه‌ای بگذارید: `* * * * * php /path/to/taskam/bin/push-cron.php`
- **اندروید:** برای رسیدن به‌موقع اعلان‌ها، بهینه‌سازی باتری کروم را «بدون محدودیت» کنید.
- **فنی:** `/manifest` (manifest)، `/service-worker` (کش فایل‌های ایستا + صفحه‌ی آفلاین + push)، `app/Services/WebPush.php` (VAPID و رمزگذاری aes128gcm بدون کتابخانه‌ی خارجی).

## امنیت (خلاصه)
- نشست: کوکی HttpOnly/SameSite، اتصال به مرورگر، انقضای عدم فعالیت، باطل شدن نشست‌ها با تغییر رمز؛ CSRF برای همه‌ی درخواست‌های تغییردهنده.
- ورود: محدودیت تلاش ناموفق به ازای «موبایل+IP»، «IP» و «خود حساب از همه‌ی IPها».
- ورود مدیر به‌جای کاربر: اگر مدیر غیرفعال/تنزل داده شود یا رمزش عوض شود، نشست فوراً باطل می‌شود.
- API: توکن‌ها فقط به‌صورت SHA-256 ذخیره می‌شوند؛ سقف `API_RATE_LIMIT` درخواست در دقیقه برای هر کاربر (پیش‌فرض ۱۲۰) و قفل موقت IP بعد از ۲۰ توکن نامعتبر.
- ضد سوءاستفاده: سقف جستجوی کاربر با موبایل (۳۰ در ۱۰ دقیقه) و ارسال پیام چت (۶۰ در دقیقه)؛ وضعیت آنلاین فقط برای مخاطبان.
- فایل‌ها خارج از webroot با بررسی MIME واقعی و دسترسی؛ پوشه‌های app/config/database/storage/bin با .htaccess بسته‌اند.
- هدرها: CSP سخت‌گیرانه (بدون اسکریپت inline)، HSTS روی HTTPS، X-Frame-Options، CORP/COOP و no-store برای صفحه‌های کاربر.
- در محیط واقعی: `APP_DEBUG=false`، `APP_URL` را تنظیم کنید و فایل `public/check.php` را حذف کنید.

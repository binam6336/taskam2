# آزمون منوی مدیر و پنل‌های جانبی ۹.۲.۰

تاریخ: ۱۴۰۵/۰۹/۰۴. محیط محلی PHP 8.4.27، MariaDB 11.8.9 و Chromium با دیتابیس آزمایشی مستقل؛ اطلاعات واقعی هاست استفاده نشد.

## تغییرات

- محتوا ← پنل کاربری ← پنج گزینه قبلی؛ وب‌سرویس از سایدبار حذف شد و مسیرهای API حذف نشدند.
- تنظیمات ← ادمین/پروفایل، امنیت/ورودها و دسترسی، مدیریت مصرف/هوش مصنوعی و ذخیره‌سازی، درباره کارلیکس و پنل‌های جانبی. منوی تیکت‌ها و دسترسی‌های موجود حفظ شد.
- دفتر پنل‌های جانبی فقط برای مدیر کل، بدون افزودن دسترسی تازه به نقش‌ها: ساخت، ویرایش، حذف و بازکردن لینک http/https در تب جدید. اطلاعات ورود اختیاری و نمایش آن مستقل از فهرست است.
- هر ردیف در content_texts با پیشوند admin.side_panel. و شناسه تصادفی نگهداری می‌شود؛ تمام JSON با Crypto و کلید موجود ContentCipher رمزگذاری و با AAD به کلید ردیف متصل است. نام کاربری و رمز در HTML اولیه یا لاگ رویدادها قرار نمی‌گیرند. درخواست نمایش POST+CSRF، پاسخ no-store؛ پاک‌کردن نمایش بعد از ۳۰ ثانیه، پنهان‌شدن تب و خروج صفحه.
- هیچ جدول، ستون یا ایندکسی تغییر نکرد؛ مستندات کاربرد جدول و PDF دیتابیس بازسازی شد (۴۸ جدول، ۴۸۱ ستون).

## نتایج واقعی

- `bin/test-side-panels.php`: هر ۱۵ بررسی گذشت؛ رمزگذاری واقعی در دیتابیس، AAD، حفظ نویسه‌های ویژه و فاصله‌های رمز، نبود اطلاعات ورود در فهرست، حفظ رمز هنگام ویرایش، حذف صریح اطلاعات اختیاری، چهار URL نامعتبر، طول ورودی، شکست امن داده دست‌کاری‌شده و جلوگیری از بازنویسی آن، حذف و شناسه نامعتبر. تراکنش آزمایش rollback شد.
- `bin/test-admin-sidebar-browser.js`: هر ۸ گروه گذشت؛ منوی تو‌در‌تو و صفحه فعال، نبود وب‌سرویس، پنج لینک محتوا، CRUD واقعی با فرم‌ها و تأیید حذف، escape عنوان HTML، نمایش/پنهان‌سازی اطلاعات ورود و no-store، پاک‌شدن واقعی DOM پس از ۳۰ ثانیه با ساعت کنترل‌شده مرورگر، حفظ و حذف رمز، رد CSRF و URL ناامن، محدوده نمایش موبایل در violet/green روشن و تیره، منع هر پنج مسیر برای مدیر داخلی فاقد مجوز و باقی‌ماندن لینک تیکت. هیچ خطای JavaScript مشاهده نشد. داده‌های آزمایش پاک شدند.
- تصاویر دسکتاپ سایدبار، موبایل تم‌های روشن/تیره و کارت پنل جانبی ذخیره و بصری بازبینی شدند؛ نمونه‌ها در `/tmp/kx-admin-sidebar-desktop.png`، `/tmp/kx-admin-sidebar-violet-dark.png` و `/tmp/kx-admin-side-panels.png` هستند و جزو مخزن نیستند.
- `bin/test-laravel-contracts.js`: هر ۷۴ مقایسه مسیر/قرارداد، از جمله تحلیل مدیر و APIهای احرازشده، گذشت.
- `bin/test-laravel-runtime.php`: کنترلرهای بومی Laravel، نشست مشترک، ORM، رمزگشایی و محرمانگی فایل‌ها گذشت.
- `bin/check-dependencies.php`: ۷۴ بسته production و ۴۰۶۰ کلاس با lock سازگارند.
- `bin/test-workload.php --laravel` و `node bin/test-workload.js`: چهار سناریو در هر دو زبان گذشت.
- syntax PHP در ۱۳ فایل مرتبط و JavaScript در سه فایل تغییرکرده، و `git diff --check` موفق بودند.
- ساخت PDF دیتابیس و استخراج متن آن موفق بود؛ توضیح admin.side_panel در فایل خروجی وجود دارد.

## محدودیت

آزمون‌ها روی محیط محلی انجام شدند؛ ورود خودکار یا آزمایش حساب در سایت‌های پنل جانبی درخواست نشده و پیاده‌سازی نشده است. کلید فعلی رمزگذاری باید حفظ شود. واگذاری پنل‌های جانبی به مدیران غیر از مدیر کل، دسترسی تعریف‌شده‌ای ندارد و در این نسخه اضافه نشده است.

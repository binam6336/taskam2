# مرحله اول مهاجرت Laravel — کامل نشده

این تغییر مهاجرت کامل بک‌اند نیست. پیش‌فرض `USER_ROUTER=legacy` می‌ماند.
پل آزمایشی Laravel 12 فقط تطبیق مسیریابی را فراهم می‌کند؛ Controllerها، Serviceها، مدل‌ها، نشست، توکن، CSRF و مجوزهای فعلی عمداً حفظ می‌شوند تا قراردادها مقایسه شوند. Responseهای فعلی PHP را خاتمه می‌دهند؛ بنابراین middlewareهای پس از پاسخ و lifecycle بومی Laravel هنوز قابل اتکا نیستند.

## اجرای آزمایشی و بازگشت

- PHP 8.2+ با افزونه‌های لازم Laravel از جمله DOM و Tokenizer؛ وابستگی‌ها در `laravel/composer.lock` برای PHP 8.2 حل شده‌اند.
- `composer install --working-dir=laravel --no-dev --prefer-dist`
- فقط در محیط آزمایشی `USER_ROUTER=laravel`؛ بازگشت با `USER_ROUTER=legacy`، بدون هیچ تبدیل دیتابیس یا داده.
- هیچ فرمان `artisan migrate` یا seed یا reset لازم یا مجاز نیست.
- مسیرهای `/admin` همیشه از روتر قدیمی عبور می‌کنند. Controllerها، Viewها و قراردادهای ادمین تغییر نکرده‌اند؛ مسیرهای ورود مشترک همچنان منطق و نشست قدیمی را دارند.
- vendor در گیت و بسته git archive نیست؛ روی هاست اشتراکی می‌توان Composer را در محیط ساخت اجرا و vendor را همراه خروجی منتقل کرد.

## تست‌های واقعی این مرحله

- PHP 8.4 و MariaDB 11.8؛ نصب Composer و check-platform-reqs موفق، Composer advisory شناخته‌شده گزارش نکرد.
- `php bin/test-recurrence.php`: روزانه، هفتگی، ماهانه، هر X روز، صدور قبل از تکمیل، جانشین یکتا، توقف و استقلال وضعیت‌ها.
- `php bin/test-project-isolation.php`: مدیر A در B مجوز ویرایش ندارد؛ تسک محرمانه B افشا نمی‌شود.
- `node bin/test-laravel-contracts.js`: ۶۷ حالت مسیر و خطا بدون احراز هویت (از جمله تمام مسیرهای API ثبت‌شده)، با متغیرهای KARLIX_TEST_MOBILE و KARLIX_TEST_PASSWORD شش خواندن API احراز‌شده و خطای شناسه نامعتبر نیز مقایسه شدند؛ صفحه تحلیل ادمین با نشست واقعی نیز پس از یکسان‌سازی CSRF مقایسه شد. مجموع ۷۴ مقایسه پاس شد.
- schema.sql، migrationها و Schema.php نسبت به نسخه قبلی تغییر ندارند؛ تست‌های دیتابیس فقط روی دیتابیس _test با rollback اجرا می‌شوند.

## باقی‌مانده ضروری

Controllerها و مدل‌ها هنوز به Eloquent منتقل نشده‌اند؛ Policyها، Form Requestها، Auth guard و Session driver بومی Laravel جایگزین نشده‌اند. تمام APIها و همه جریان‌های فرانت‌اند تست نشده‌اند. امنیت کل بک‌اند ممیزی کامل نشده است و مهاجرت تولیدی نباید کامل تلقی شود. مقایسه محدود قراردادها جایگزین تست تمام endpointها نیست.

در قدم‌های بعد هر دامنه باید با Controller/Service/Policy/Form Request بومی و مدل متناظر همین جدول‌ها منتقل شود؛ سپس قراردادهای مثبت و منفی و پنل ادمین روی هر مرحله تکرار شوند. تغییر موتور پیش‌فرض پس از این مراحل معنی دارد.

Graphify فراخوانی شد، اما این اتصال no_authorized_repositories برگرداند؛ هیچ گراف قابل استفاده‌ای در دسترس نبود و بررسی روی فایل‌های checkout انجام شد.

فهرست کامل مسیرهای غیرادمین در `user-routes.json` ثبت شده و با `php bin/export-route-contracts.php` بازتولید می‌شود. این فهرست فقط قرارداد مسیر و middleware را ثبت می‌کند؛ به معنی بازنویسی handlerها نیست.
